# 🚦 UK Road Accidents Data Analysis (2021–2022)

An end-to-end Data Analytics project analyzing UK road accident data (2021–2022) using **Excel**, **SQL Server**, and **Power BI**.

The project transforms raw accident records into meaningful insights through data cleaning, exploratory analysis, SQL querying, and interactive dashboards to support data-driven road safety decisions.

---

# 📌 Project Overview

Road traffic accidents remain one of the major public safety challenges. This project analyzes more than **307,000 accident records** and **417,000+ casualties** to identify patterns related to accident severity, road type, weather conditions, vehicle type, location, and time.

The project follows a complete data analytics workflow starting from raw data preparation to building interactive dashboards and extracting actionable insights.

---

# 🎯 Project Objectives

- Clean and prepare raw accident data.
- Build a structured SQL database.
- Perform Exploratory Data Analysis (EDA).
- Analyze accident trends and contributing factors.
- Design interactive dashboards in Excel and Power BI.
- Provide data-driven recommendations to improve road safety.

---

# 📊 Dataset Information

- **Dataset:** UK Road Accidents (2021–2022)
- **Source:** UK Government Open Data
- **Records:** 307,973 Accidents
- **Casualties:** 417,883
- **Vehicles Involved:** 563,302

# 💡 Key Insights

- Most accidents occurred on **Single Carriageway** roads.
- Cars were involved in the highest percentage of accidents.
- Most accidents happened during **Daylight** conditions.
- Dry road surfaces recorded the largest number of accidents.
- Friday showed the highest accident frequency.
- Urban areas experienced more accidents than rural areas.
